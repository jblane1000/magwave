# Checklist — release

## Before tagging
- [ ] `main` green: lint, format, tests, benchmark suite, licence check.
- [ ] CHANGELOG updated under the new version, with any numeric change called out explicitly.
- [ ] Version bumped in `pyproject.toml` and `src/magwave/__init__.py` (test asserts equality).
- [ ] `docs/BENCHMARKS.md` regenerated by CI from this commit.
- [ ] PRD requirement statuses updated (satisfied / unverified / withdrawn).
- [ ] Deprecated things: removed or marked, never quietly left.

## Numbers and claims
- [ ] Every new number in README/docs names its rung (analytic, TEAM, second code, measurement).
- [ ] No claim of parity with a commercial package beyond the published parity matrix.
- [ ] Tolerances changed? Then the changelog says why, with evidence.

## Artefacts
- [ ] Git tag `vX.Y.Z` (annotated) pushed.
- [ ] GitHub release with notes copied from CHANGELOG.
- [ ] Wheel + sdist built and installed in a clean virtualenv; `magwave --version` correct.
- [ ] Licence files present in the artefact (Apache-2.0 text, NOTICE, Qt notices).

## After release
- [ ] Install from the release artefact on a second machine (or a fresh container) and run one benchmark.
- [ ] Tag archived in the backup rotation like any other estate asset.
